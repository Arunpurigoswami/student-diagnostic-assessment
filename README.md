# Explainable NLP-Based Diagnostic Assessment of Student Reasoning

Research prototype for diagnosing errors in free-form student answers.

## Planned pipeline

Question + Reference Answer + Rubric + Student Answer
-> Reasoning Extraction
-> RAG / Evidence Retrieval
-> Evidence Alignment
-> Reasoning Verification
-> First-Error Localization
-> Error Classification
-> Rubric-Based Scoring
-> Explainable Diagnosis
-> Targeted Feedback

## Status

Version 0.1: project foundation only. Components will be implemented incrementally.
